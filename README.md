## 📚 Section Breakdown

### 1. `Observation/`
Contains laboratory practical observations covering the full-stack curriculum:
- **`Observation.pdf`**: Official 24-page comprehensive laboratory observation record covering Experiments 1 through 9 (HTML5 & CSS3 fundamentals, Pomodoro Timer, Audio/Video tags, JS Arrays & Functions, Dynamic Webpages, Node.js Modules, Express Student Management System, React Components & State, JSON Server CRUD operations, and MongoDB + Mongoose REST APIs).
- **`PDFs/`**: Topic-wise laboratory observation PDFs.

### 2. `E-Record/`
Contains official laboratory electronic records (E-Records) with finalized practical experiments, source code proofs, and evaluation criteria.

### 3. `Assignments/`
- **`Assignment-1/`**: Academic submission PDF [`Assignment-1.pdf`](file:///Users/rajesh/.gemini/antigravity/scratch/full-stack-web-development/Assignments/Assignment-1/Assignment-1.pdf) on Full-Stack fundamentals.
- **`Assignment-2-Individual-Project/`**: **Smart Traffic Signal Optimisation System** built using HTML, CSS, React.js, and a sample dummy database (`data.json`). Features 4-way intersection visualization, adaptive density-weighted green timing, and emergency corridor overrides.

### 4. `Group-Project/`
- **RecoAI – E-Commerce Recommendation Engine**: Full-stack application combining a modern React + TypeScript (Vite) frontend with a Python Flask REST API, MongoDB storage, and Apriori Association Rule Mining (`mlxtend`) to deliver real-time product recommendations based on market basket analysis.
